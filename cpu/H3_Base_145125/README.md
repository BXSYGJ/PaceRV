# PaceRV Base

This directory contains the frozen PaceRV Base RV32IMC system at 145.125 MHz. V0 is the 6,000-iteration performance image; V1 is the separate 6,000-iteration validation image.

- [Build, simulate, and measure](../../docs/getting-started.md)
- [Measurement settings and results](../../docs/reproducibility.md)
- [Machine-readable measurements](PERFORMANCE.json)
- [Exact reproduction recipe](recipe.json)

Source snapshots, firmware, bitstreams, archived full UART captures, and timing reports are included. Pango native-memory models are provided from the user's separately installed PDS library using -NativeModelDirectory; they are not redistributed.
