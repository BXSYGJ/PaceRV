# PaceRV

PaceRV 是采用 SystemVerilog 实现的**单发射、五级流水线 RV32IMC FPGA 软核**，板级实测达到 **3.442 CoreMark/MHz**。研究重点是访存请求的接纳时机，以及提前计算的乘法结果在流水线等待期间的复用。

本仓库发布 145.125 MHz 的 Base 和 Retained 两套完整实现，包含处理器、缓存、CSR、UART/GPIO 外设、固件、板级构建输入、比特流、实测串口记录和时序报告。原始目录中的 H3 是 PaceRV 以前的内部名称；保留这些目录和模块名称有助于核对已发表实验的源码哈希。

**3.442 CoreMark/MHz 来自保留完整 SoC 外设和动态监测功能的实现。** 系统包含 UART 收发及 FIFO、8 位 GPIO、64 位定时器与比较器、定时器/软件/外部中断、机器态 CSR、64 位周期与退休指令计数器，以及实时缓存命中、未命中和写回统计。下表资源数也包含这些模块。

| 实现 | CoreMark/MHz | LUT / FF | BRAM / DSP | 已计入 0.150 ns 不确定性的建立时间余量 |
|---|---:|---:|---:|---:|
| Base | 3.441903 | 6,097 / 2,541 | 25 / 4 | +0.047 ns |
| Retained | 3.442075 | 6,150 / 2,541 | 25 / 4 | +0.016 ns |

两套实现均保留 6,000 次迭代的性能与验证固件，以及每种固件三次冷启动的完整串口记录。硬件构建使用 PDS 2022.2-SP6.4；专有仿真模型由用户从本机 PDS 安装目录提供。无需 PDS 的 RTL 单元测试也包含在仓库中。
